## Long version (story)

🚀 I rebuilt a medical-supply company's website from the ground up — and gave it a look that stands out in a very traditional industry.

MedTech Supplies is a medical-equipment *sourcing partner*: they buy from wholesalers and supply hospitals, clinics and pharmacies across South Africa. A standard e-commerce store didn't fit, so I designed an **enquiry-first experience** — clients browse the catalogue, build an enquiry basket, and the team replies with a tailored quote. No public prices, which suits their B2B model.

Then I made it *memorable*: a dark, futuristic UI with real motion.

🛠️ Tech stack
• ASP.NET Core 8 · Blazor Web App (Interactive Server) · C#
• Entity Framework Core (SQLite in dev → Azure SQL-ready)
• Cookie-based auth for a staff back-office
• Pluggable transactional email — SendGrid / Brevo / SMTP with branded HTML templates
• 100% hand-written CSS + vanilla JS motion — no UI framework
• Azure App Service–ready · built in JetBrains Rider

✨ What makes it pop
• Animated particle-network hero on a canvas
• Glassmorphism, 3D tilt-and-glow cards, scroll parallax & reveals
• A rotating headline and animated stat counters
• A custom "AI assistant" chat widget (typing indicator + smart canned replies)
• A back-office enquiries inbox that emails the team and confirms to the client
• Fully responsive, accessible (respects reduced-motion), SAHPRA-compliant branding
